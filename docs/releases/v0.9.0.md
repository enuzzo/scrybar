# ScryBar v0.9.0

Firmware **DB-M0-r300** · Companion **v0.3.1 (36)** · 2 September 2026

## Highlights

- Adds a native Bambu Lab view with live LAN telemetry, print progress, temperatures, layers, ETA, speed, fans, Wi-Fi, AMS slots, filament colours and status/error context.
- Adds Bambu printer discovery, duplicate suppression, saved LAN identity/IP fallback, retry controls, onboarding help, connection feedback and lifecycle sounds to the macOS Companion.
- Redesigns the Companion around a clearer black, white, grey and Bambu-green hierarchy, with a popover that expands to the available screen height.
- Adds drag-and-drop view reordering to the web configurator.
- Moves ScryBar to the Dosis type family and retunes typography, weights, alignment and contrast across all views and themes.
- Replaces the weather artwork with 19 live WMO-driven Meteocons variants. The large current icon animates at a calmer 5 fps; the compact forecast remains static and high-contrast.
- Restores Now Playing artwork delivery and adds album metadata when the media source exposes it.

## Downloads

- **Web installer:** flash firmware r300 directly from the ScryBar website with a Chromium-based browser.
- **ScryBar Companion 0.3.1:** universal macOS DMG for Apple Silicon and Intel Macs.
- **Firmware binaries:** attached for manual installation and also published with the web installer.

## Notes

- Bambu Lab integration uses the printer's local MQTT interface. The LAN access code stays in the macOS Keychain and is never sent to ScryBar.
- The Companion DMG is ad-hoc signed for this community release and is not Apple-notarized.
- See `CHANGELOG.md` for the full technical change list.
